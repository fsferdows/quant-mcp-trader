# Support

Need help setting up **Quant MCP Trader**, running backtests, or connecting the 4 MCP servers?

- **Documentation**: Start with [README.md](README.md) and the workspace skills in [`.agents/plugins/freqtrade-trading/skills/`](.agents/plugins/freqtrade-trading/skills/).

- **Strategy Submissions**: Use the [Strategy Proposal template](.github/ISSUE_TEMPLATE/strategy_proposal.md) and include `lookahead-analysis` and `recursive-analysis` results.
- **Maintainer Contact**: Reach **FS Ferdows** via [GitHub](https://github.com/fsferdows) or `fsferdows@icloud.com`.
